## 一、卡片类组件

### Card 基础卡片

<Card title="卡片标题" icon="plane" href="/travelling/2026/shanxi">
  这是卡片描述，点击可跳转
</Card>

```mdx
<Card title="标题" icon="图标名" href="/链接">
  描述内容
</Card>
```

### Card 横向卡片

<Card title="横向卡片" icon="map" href="#" horizontal>
  横向布局更紧凑
</Card>

```mdx
<Card title="标题" icon="图标" href="#" horizontal>
  描述
</Card>
```

### Card 带图片

<Card title="带图片的卡片" img="/images/hero-light.png">
  可以添加顶部图片
</Card>

```mdx
<Card title="标题" img="/images/xxx.png">
  描述
</Card>
```

### Columns 多列布局

<Columns cols={2}>
  <Card title="左边" icon="map">左边内容</Card>
  <Card title="右边" icon="camera">右边内容</Card>
</Columns>

```mdx
<Columns cols={2}>
  <Card title="左边">内容</Card>
  <Card title="右边">内容</Card>
</Columns>
```

<Columns cols={3}>
  <Card title="第一列" icon="1">内容</Card>
  <Card title="第二列" icon="2">内容</Card>
  <Card title="第三列" icon="3">内容</Card>
</Columns>

```mdx
<Columns cols={3}>
  <!-- 支持 1-4 列 -->
</Columns>
```

## 二、提示框组件 Callout

### Note 普通提示

<Note>这是一条普通提示信息</Note>

```mdx
<Note>提示内容</Note>
```

### Tip 小技巧

<Tip>这是一个实用小技巧</Tip>

```mdx
<Tip>技巧内容</Tip>
```

### Info 说明信息

<Info>这是说明信息</Info>

```mdx
<Info>说明内容</Info>
```

### Warning 警告

<Warning>这是警告信息，请注意！</Warning>

```mdx
<Warning>警告内容</Warning>
```

### Check 成功/完成

<Check>操作已成功完成</Check>

```mdx
<Check>成功内容</Check>
```

### Danger 危险

<Danger>危险操作，请谨慎！</Danger>

```mdx
<Danger>危险内容</Danger>
```

## 三、折叠面板 Accordion

### 单个折叠

<Accordion title="点击展开查看详情">
  这里是隐藏的详细内容。
  
  可以包含任何内容，包括图片、代码等。
</Accordion>

```mdx
<Accordion title="标题">
  隐藏内容
</Accordion>
```

### 默认展开

<Accordion title="默认展开的面板" defaultOpen>
  这个面板默认是展开状态
</Accordion>

```mdx
<Accordion title="标题" defaultOpen>
  内容
</Accordion>
```

### 带图标

<Accordion title="带图标的面板" icon="star">
  可以添加图标让标题更醒目
</Accordion>

```mdx
<Accordion title="标题" icon="star">
  内容
</Accordion>
```

### 折叠组 AccordionGroup

<AccordionGroup>
  <Accordion title="问题一：如何开始？">
    这是问题一的回答
  </Accordion>
  <Accordion title="问题二：有什么技巧？">
    这是问题二的回答
  </Accordion>
  <Accordion title="问题三：遇到问题怎么办？">
    这是问题三的回答
  </Accordion>
</AccordionGroup>

```mdx
<AccordionGroup>
  <Accordion title="问题一">回答一</Accordion>
  <Accordion title="问题二">回答二</Accordion>
</AccordionGroup>
```
